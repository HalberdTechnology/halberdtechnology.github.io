Start a game

  1. Everyone installs Revolution and picks a callsign.
  2. One player taps Host game and reads out the room code.
  3. Everyone else taps Join game and types the code.
  4. The host starts the round once everyone is in.

Playing alone? Choose to play against bots from the menu.

Questions

Do we need internet?

Yes, for online games. They connect through our relay server, so each phone needs mobile data or Wi-Fi. A steady connection gives the best game, so expect the odd hiccup in tunnels.

How many people can play?

Two to six. You can also play solo against bots.

Why does it ask for local network access?

So phones on the same Wi-Fi or hotspot can find each other directly. It is only used to connect to other players' phones. You can change it in Settings > Privacy & Security > Local Network.

The room code doesn't work.

Check that the host is still in the lobby and that the code was typed exactly. Codes only last while the host's room is open, so if the host left, have them host again.

Is it on Android?

Not yet. Revolution is iPhone-only for now.

What does the app collect?

Nothing that identifies you. The details are in the privacy policy.
